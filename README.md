# 智能售后工单助手 · 三端高保真原型

AI 优先的轻量售后工具：连锁网点软硬件维护报修 × 品牌上门服务调度。

**入口**：打开 [prototype/index.html](prototype/index.html)（线上地址见 GitHub Pages）

## 内容

| 目录 | 说明 |
|---|---|
| `prototype/` | 三端可交互高保真原型（用户端 / 管理端 / 工程师端 / 槽位配置 DEMO） |
| `docs/` | 产品文档：PRD、详细功能设计、AI 工作台设计、工单模型与触发引擎设计 |

## 三端

- **用户端**（`user.html`）：豆包式会话，AI 引用企业知识库作答，AI 填单一键转工单，逃生门常驻
- **管理端**（`admin.html`）：AI 工作台（Agent 协同 + 人工服务台 + 指令式工单操作）、派单台、数据看板
- **工程师端**（`engineer.html`）：小程序原型，接单 → 定位签到 → 结单，开单即带相似案例，工单协同 + 问一问

## 访问保护

线上原型由前端密码门保护（演示级）。密码不存于仓库，如需修改：改 `prototype/gate.js` 中的 `PWD_HASH`（新密码的 SHA-256）后重新部署。

## 设计语言

品牌蓝 `#2454FF` · 思源黑体 · 清言式组件（Phosphor 图标 + Noto Sans SC 已本地化，离线可用）
